# Education policy mapping

Verified against official Ministry/government sources on **11 October 2026**. The editable catalog is `backend/src/main/resources/ai/education-policy-catalog.json`. Policy lookup does not call Gemini; selection is deterministic and the resulting references are supplied to the import model and shown in the instructor dialog.

Grade range is checked against level. Unknown subject names receive an incomplete-mapping note. The 17/2025 amendment is selected for affected subject/grade combinations; it is not automatically attached to every subject. The grade supports integers or `Lớp N` / `Khối N` labels.

Import references depend only on education level, subject, grade and school year. Textbook names are optional extraction hints and are not sent to the policy lookup endpoint. Changing or omitting the textbook does not change selected regulations, block an import or trigger a book-specific warning. The catalog retains textbook policy facts for explicit chatbot questions. Historical documents before the fully implemented 2024–2025 program and future years beyond this verification date trigger corresponding notes.

University/vocational specialty subjects (such as Mobile Programming) must not use primary/secondary lesson-plan rules. `HIGHER_EDUCATION` means university-level education; vocational college belongs in `VOCATIONAL`. General education continuing programs are separate: [78/2026](https://vanban.chinhphu.vn/?docid=219645&pageid=27160) is effective 10 November 2026 and modifies36/2021 and12/2022. Select **Khác / giáo dục thường xuyên** for these currently unsupported programs. Program type must not be inferred from an optional textbook name.

[82/2026](https://vanban.chinhphu.vn/?docid=219689&pageid=27160) concerns vocational **common** subjects and is effective 15 November 2026. It must not be assigned indiscriminately to specialist modules. These upcoming references are documented for update work, with their dates; the snapshot does not treat future-effective documents as currently applicable.

The catalog contains concise curated summaries, not all textbook text or the full legal corpus. Import retains what the uploaded plan actually contains and returns missing-content warnings instead of generating missing objectives as if they were in the file. The output is a reviewed LMS draft, not a statement that all national/local legal requirements have been fulfilled.

The 5512 appendix is a reference framework; [official guidance describing2613](https://hungyen.gov.vn/dai-hoi-dai-bieu-dang-bo-cac-co-quan-dang-tinh-lan-thu-i-nhiem-ky-2025-2030-thanh-cong-tot-dep-c282890.html/trien-khai-thuc-hien-chuong-trinh-giao-duc-trung-hoc-cho-nam-hoc-2021-2022-c274342.html) expressly describes the appendices as references. Missing activity labels produce review notes, not a legal violation or rejection. Four activity types within one plan remain inside one lesson, rather than automatically becoming four LMS lessons.

The signed15/2026 document does not establish35/45 minutes as a single LMS lesson duration; its35/45 figures in the class-size provision are student counts. Period duration comes from the [Ministry's general curriculum page](https://moet.gov.vn/tintuc/Pages/CT-GDPT-Tong-The.aspx?ItemID=8421) and the current [2026–2027 primary implementation guidance](https://home.haiphong.edu.vn/tin-tuc-su-kien/huong-dan-thuc-hien-nhiem-vu-giao-duc-tieu-hoc-nam-hoc-2026-2027/cthp/10/6700):35 minutes for primary and45 for secondary. Import supplies this conversion context only for supported ordinary-school profiles; only an explicit number of periods in the source can be converted. It never assigns a fixed35/45 minutes merely because of education level and does not infer video length from it. The reviewed09/2021 text also has no10–15 or20–25 minute video cap, so those numbers are not stored as legal validation rules. Timings remain source-derived and instructor-editable.

When updating the catalog, verify issuer, actual signed text, effective date, affected grades/subjects and repeal/amendment relationships, then change `verifiedAt` with the same code review. Do not ingest search snippets, unofficial copies or model-created citations as authoritative content.
